# Phase 7.2 handover

Phase 7.2 leaves FoxTutor in control of recurring lessons, lesson billing
events, customer credit, readiness and operational audit. FreeAgent remains the
accounting/provider boundary and the existing FreeAgent-GoCardless integration
remains the only Direct Debit authority.

Before enabling financial production operations, a human must confirm approved
FreeAgent billing/category/tax settings, the intended cancellation accounting
policy, Sandbox evidence and the operational contact/mandate workflow. Those
approvals cannot be inferred from code or controlled seam tests.
